# Contributing

Thanks for your interest in the guuey SDKs!

**Issues and discussions are welcome right here.** Bug reports, feature
requests, and questions about any `@guuey/*` package belong in this
repository's issue tracker.

**A note on pull requests:** this repository is developed inside a larger
monorepo and published here automatically, so commits cannot land on this
repository directly — a maintainer will port an accepted change upstream
and it will appear here (with credit) in the next sync. Small, focused
PRs are still useful as concrete proposals; for larger changes, please
open an issue first so we can agree on the approach before you invest
the time.

Releases to npm are cut from this repository via `release.yml`, so the
code you see here is exactly what ships.
